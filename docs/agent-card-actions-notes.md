# Agent card actions

Owned agent cards expose a compact quick-actions menu without nesting interactive controls inside the card navigation link.

The first increment intentionally exposes only actions backed by existing product flows:

- Edit agent opens the existing agent settings dialog.
- Start channel opens the existing new-channel flow for that agent.

Additional entries such as model/API, computer lifecycle, skills, knowledge, and permissions should be added only when their underlying settings and mutations exist.
